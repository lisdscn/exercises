# 国庆作业
## 一、

$C_c^\infty(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中的稠密性

**证明：** 光滑紧支撑函数 $C_c^\infty(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中稠密，其中 $1 \le p < \infty$。

### Proof:

#### 1. 证 $C_c(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中稠密

简单函数在 $L^p$ 中稠密，故只需对可测集 $E \subset \mathbb{R}^n,\ m(E) < \infty$ 的示性函数 $\chi_E$ 作逼近。

由 Lebesgue 测度的正则性，给定紧集 $K \subset E$ 与开集 $U \supset E$，使得

$$m(U \setminus K) < \varepsilon^p.$$

$\exists\ \phi \in C_c(\mathbb{R}^n),\ 0 \le \phi \le 1$，且 $\phi(x) \equiv 1\ (x \in K)$，$\phi(x) \equiv 0\ (x \in U^c)$。

故

$$|\phi - \chi_E| = \begin{cases} 0, & x \in U^c \cup K \\ \le 1, & x \in U \setminus K \end{cases}$$

因此

$$\|\chi_E - \phi\|_p^p \le m(U \setminus K) \le \varepsilon^p, \quad \text{即}\ \|\chi_E - \phi\|_p < \varepsilon.$$

由 $\forall f \in L^p(\mathbb{R}^n)$，$f$ 可由简单函数逼近；简单函数可由连续紧函数逼近，故 $\exists g \in C_c(\mathbb{R}^n)$，使 $\|f - g\|_p < \varepsilon$。

$\therefore\ C_c(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中稠密。

#### 2. 可以把 $C_c(\mathbb{R}^n)$ 逼近到 $C_c^\infty$

令 $\text{supp}\,f = \{x \mid f(x) \ne 0\}$，取 $\eta \in C_c^\infty(\mathbb{R}^n)$ 满足 $\eta \ge 0$，$\int_{\mathbb{R}^n} \eta\,dx = 1$，且 $\text{supp}\,\eta \subset B(0,1)$。

记 $\eta_\varepsilon(x) = \varepsilon^{-n}\eta\!\left(\dfrac{x}{\varepsilon}\right)$，$\forall g \in C_c(\mathbb{R}^n)$，有

$$g_\varepsilon(x) = \int_{\mathbb{R}^n} g(y)\,\eta_\varepsilon(x-y)\,dy.$$

而

$$g_\varepsilon^{(\alpha)}(x) = \int_{\mathbb{R}^n} g(y)\,\eta_\varepsilon^{(\alpha)}(x-y)\,dy,$$

那么 $g_\varepsilon$ 为任意阶可导。

若 $\text{supp}\,g \subset B(0,R)$，则 $\text{supp}\,g_\varepsilon \subset \overline{B(0,R+\varepsilon)} \subset \overline{B(0,R+1)}$，当 $\varepsilon \le 1$。

由 $g$ 紧支撑，故 $g$ 一致连续，

$$|g_\varepsilon - g| \le \int |g(x-y) - g(x)|\,\eta_\varepsilon(y)\,dy \le \sup_{|y|<\varepsilon}|g(x-y) - g(x)| \to 0 \quad (\varepsilon \to 0).$$

记 $H = \overline{B(0,R+1)}$，则 $\|g_\varepsilon - g\| \le m(H)\|g_\varepsilon - g\|_\infty \to 0$。

故我们可以通过 $\eta$ 把 $C_c$ 逼近 $C_c^\infty$。

则 $\forall f \in L^p,\ \varepsilon > 0$，$\exists g \in C_c$，使 $\|f - g\|_p < \dfrac{\varepsilon}{2}$；$\delta \le 1$，$g_\delta \in C_c^\infty$，且

$$\|g - g_\delta\| < \frac{\varepsilon}{2}.$$

于是

$$\|f - g_\delta\| \le \|f - g\| + \|g - g_\delta\| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.$$

那么 $C_c^\infty(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中稠密。 $\blacksquare$

## 二、赋范线性空间相关证明

### 习题 1.2

3. 令 $L$ 为赋范线性空间，$L \times L$ 按照线性运算

$$\alpha(x_1,y_1) + \beta(x_2,y_2) = (\alpha x_1 + \beta x_2,\ \alpha y_1 + \beta y_2)$$

成为线性空间。在 $L \times L$ 上定义两个范数：

$$\|(x,y)\|_1 = \sqrt{\|x\|^2 + \|y\|^2}, \qquad \|(x,y)\|_2 = \max\{\|x\|, \|y\|\}.$$

**(i)** 证明：$(L \times L, \|\cdot\|_1)$ 与 $(L \times L, \|\cdot\|_2)$ 为赋范线性空间。

**(ii)** 作 $(L \times L, \|\cdot\|_1)$ 到 $(L \times L, \|\cdot\|_2)$ 的映射：

$$\varphi: (x,y) \mapsto (x', y'), \qquad (x', y') = (x,y)\begin{pmatrix} a & b \\ c & d \end{pmatrix},$$

其中 $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ 为非奇异的。证明：$\varphi$ 为拓扑同胚（$\varphi$ 为一一映射，且 $\varphi$ 与 $\varphi^{-1}$ 均为连续的）。

#### Proof:

**(i)** 任取 $(x,y) \in L \times L$，其中 $\|x\| \ge 0,\ \|y\| \ge 0$。令 $\alpha \in \mathbb{K}$。

先考虑 $(L \times L, \|\cdot\|_1)$：

$$\|(x,y)\|_1 = \sqrt{\|x\|^2 + \|y\|^2} \ge 0,$$

且

$$\|(x,y)\|_1 = 0 \iff \|x\| = \|y\| = 0 \iff x = y = 0 \iff (x,y) = (0,0),$$

满足正定性。

$$\|\alpha(x,y)\|_1 = \|(\alpha x, \alpha y)\|_1 = \sqrt{\|\alpha x\|^2 + \|\alpha y\|^2} = |\alpha|\,\|(x,y)\|_1,$$

满足齐次性。

而三角不等式：$\|(x_1+x_2, y_1+y_2)\|_1 \le \|(x_1,y_1)\|_1 + \|(x_2,y_2)\|_1$，只需要满足

$$\|x_1\|\|x_2\| + \|y_1\|\|y_2\| \le \sqrt{\|x_1\|^2 + \|y_1\|^2}\sqrt{\|x_2\|^2 + \|y_2\|^2},$$

而这为 Cauchy–Schwarz 不等式，显然成立。

即 $(L \times L, \|\cdot\|_1)$ 为赋范线性空间。

再考虑 $(L \times L, \|\cdot\|_2)$：

$$\|(x,y)\|_2 \ge \|x\| \ge 0,$$

$$\|(x,y)\|_2 = 0 \iff 0 \le \|x\|,\ \|y\| \le 0 \iff x = y = 0 \iff (x,y) = (0,0),$$

满足正定性。

$$\|\alpha(x,y)\|_2 = \|(\alpha x, \alpha y)\|_2 = \max\{|\alpha|\|x\|, |\alpha|\|y\|\} = |\alpha|\,\|(x,y)\|_2,$$

满足齐次性。

而

$$\|x_1\|+\|x_2\|,\ \|y_1\|+\|y_2\| \le \max\{\|x_1\|,\|y_1\|\} + \max\{\|x_2\|,\|y_2\|\},$$

即 $\|(x_1+x_2, y_1+y_2)\|_2 \le \|(x_1,y_1)\|_2 + \|(x_2,y_2)\|_2$，满足三角不等式。

故 $(L \times L, \|\cdot\|_2)$ 为赋范线性空间。

**(ii)** 由 $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ 为非奇异的，故 $(x,y)$ 与 $(x', y')$ 一一对应，$\varphi$ 为双射。

由 $\varphi(x,y) = (x', y') = (ax + cy,\ bx + dy)$，

$$\|\varphi(x,y)\|_2 \le a_1\|x\| + a_2\|y\| \le (a_1 + a_2)\|(x,y)\|_1,$$

其中 $a_1 = \max\{|a|, |b|\}$，$a_2 = \max\{|c|, |d|\}$。

故 $\varphi$ 为有界线性算子。而 $(x_n, y_n) \xrightarrow{\|\cdot\|_1} (x, y)$，则

$$\|\varphi(x_n, y_n)\|_2 \le (a_1+a_2)\|(\Delta x, \Delta y)\|_1 \to 0,$$

（$\Delta x = x_n - x$，$\Delta y = y_n - y$）。

$\varphi$ 为连续的且 $\varphi$ 为双射，故 $\varphi$ 为拓扑同胚。 $\blacksquare$

6. 设 $C_b(0,1]$ 表示在 $(0,1]$ 上处处连续且有界的函数全体，且

$$\|x\| = \sup_{0 < t \le 1}|x(t)|, \quad x \in C_b(0,1].$$

**(i)** 证明：$\|x\|$ 为空间 $C_b(0,1]$ 上的范数，且 $C_b(0,1]$ 按 $\|\cdot\|$ 成为赋范线性空间。

**(ii)** $C_b(0,1]$ 中点列 $\{x_n\}$ 按范数 $\|\cdot\|$ 收敛于 $x_0$ 的充要条件为 $\{x_n\}$ 在 $(0,1]$ 上一致收敛于 $x_0$。

#### Proof:

**(i)** 由 $|x(t)| \ge 0$，$\|x\| = \sup_{0<t\le1}|x(t)| \ge 0$。

$$\|x\| = 0 \iff m\bigl(\{t: |x(t)| > 0\}\bigr) = 0 \iff x = 0\ \text{a.e.},$$

满足正定性。

对 $|\alpha x(t)| = |\alpha|\,|x(t)|$ 两边取 $(0,1]$ 上的上确界，

$$\|\alpha x\| = \sup_{0<t\le1}|\alpha x(t)| = |\alpha|\sup_{0<t\le1}|x(t)| = |\alpha|\,\|x\|,$$

满足齐次性。

$|x(t)+y(t)| \le |x(t)| + |y(t)|$，先对右边取 $(0,1]$ 的上确界，之后再对左边取上确界，得 $\|x+y\| \le \|x\| + \|y\|$。

故 $\|x\|$ 为空间 $C_b(0,1]$ 上的范数。

**(ii)** $C_b(0,1]$ 中点列 $\{x_n\}$ 按范数 $\|\cdot\|$ 收敛于 $x_0$：

$$\begin{aligned}
&\iff \forall \varepsilon > 0,\ \exists N,\ \text{使}\ \|x_n - x_0\| < \varepsilon,\ \text{只要}\ n > N \\
&\iff \forall \varepsilon > 0,\ \exists N,\ \text{使}\ |x_n(t) - x_0(t)| < \varepsilon,\ \text{只要}\ n > N,\ t \in (0,1] \\
&\iff \{x_n\}\ \text{在}\ (0,1]\ \text{上一致收敛于}\ x_0.
\end{aligned}$$

$\blacksquare$ 

10. 设 $H$ 为内积空间，如果 $x_1, x_2, \ldots, x_n$ 是 $H$ 中的向量，它们满足 $\langle x_i, x_j \rangle = \delta_{ij}$。证明：$x_1, x_2, \ldots, x_n$ 为一组线性无关向量。

#### Proof:

存在 $a_1, a_2, \ldots, a_n \in \mathbb{K}$，使 $\displaystyle\sum_{j=1}^n a_j x_j = 0$。

取 $\displaystyle\Big\langle x_i,\ \sum_{j=1}^n a_j x_j\Big\rangle = 0 = \sum_{j=1}^n a_j \delta_{ij} = a_i,\quad i = 1, 2, \ldots, n$。

故 $a_1 = a_2 = \cdots = a_n = 0$，即 $x_1, x_2, \ldots, x_n$ 为一组线性无关的向量。 $\blacksquare$

12. 令 $H$ 为 Hilbert 空间。

**(i)** 对于 $x \in H$，$x \perp H$ 的充要条件为 $x = 0$。

**(ii)** 对于 $H$ 中的子集 $A$，$A^\perp$ 为闭的线性子空间。

**(iii)** 若子集 $M \subset N \subset H$，则 $M^\perp \supset N^\perp$。

**(iv)** 对线性子空间 $M$，有 $M \cap M^\perp = \{0\}$。

**(v)** 令 $L = \text{span}\{M, N\}$，则 $L^\perp = M^\perp \cap N^\perp$。

#### Proof:

**(i)** $(\Rightarrow)$ 反证：假设存在 $x_1 \ne 0$，使 $x_1 \perp H$。

取 $\langle x_1, x_1 \rangle > 0$，而这与假设矛盾，故 $x = 0$。

$(\Leftarrow)$ $x = 0$，则 $\forall y \in H$，有 $\langle x, y \rangle = \langle 0, y \rangle = 0$，故 $x \perp H$。

**(ii)** 取 $x_1, x_2 \in A^\perp$，有 $a_1 x_1 + a_2 x_2 \perp A$，故 $A^\perp$ 为线性子空间。

令 $\{x_n\}$ 为 $A^\perp$ 中的 Cauchy 列，而 $\{x_n\} \subset A^\perp \subset H$，故存在 $x_0 \in H$，使 $\lim_{n\to\infty} x_n = x_0$。

由于 $\forall y \in A$，

$$\langle x_0, y \rangle = \lim_{n\to\infty}\langle x_n, y \rangle = 0 \implies x_0 \in A^\perp.$$

故 $A^\perp$ 为闭的子空间。

**(iii)** $\forall x \in N^\perp$，$\forall y \in N \subset M$，有 $\langle x, y \rangle = 0$，故 $x \in M^\perp$，即 $N^\perp \subset M^\perp$。

**(iv)** 令 $x \in M \cap M^\perp$，则必须有 $\langle x, x \rangle = 0$，即 $x = 0$。

**(v)** $\forall x \in L^\perp$，由题 $\forall y \in L$，有 $y = m + n$，$m \in M$，$n \in N$。

$$\langle x, y \rangle = 0 \implies x \in M^\perp\ \text{且}\ x \in N^\perp \implies L^\perp \subset M^\perp \cap N^\perp.$$

令 $h \in M^\perp \cap N^\perp$，而 $\forall y \in L$，有 $y = m + n$，$m \in M$，$n \in N$。

故 $\langle h, y \rangle = \langle h, m \rangle + \langle h, n \rangle = 0 \implies h \in L^\perp \implies M^\perp \cap N^\perp \subset L^\perp$。

$\therefore\ M^\perp \cap N^\perp = L^\perp$。 $\blacksquare$

1. 令 $\mathcal{F} = \{e_\lambda,\ \lambda \in \Lambda\}$ 为 Hilbert 空间 $H$ 的标准基。证明：对任何 $x, y \in H$，

$$\langle x, y \rangle = \sum_{\lambda \in \Lambda} \langle x, e_\lambda \rangle\,\overline{\langle y, e_\lambda \rangle}.$$

#### Proof:

$$\langle x, y \rangle = \Big\langle \sum_{\lambda \in \Lambda}\langle x, e_\lambda\rangle e_\lambda,\ y \Big\rangle = \sum_{\lambda \in \Lambda}\langle x, e_\lambda\rangle\langle e_\lambda, y\rangle.$$

由 $\langle x, y \rangle = \overline{\langle y, x \rangle}$，故

$$\langle x, y \rangle = \sum_{\lambda \in \Lambda}\langle x, e_\lambda\rangle\,\overline{\langle y, e_\lambda\rangle}. \quad \blacksquare$$

3. 令 $L^2([0,2\pi]\times[0,2\pi])$ 上的内积为

$$\langle f, g \rangle = \iint_{[0,2\pi]\times[0,2\pi]} f\,\bar{g}\,\frac{dx\,dy}{4\pi^2}.$$

证明：$\{e^{imx}e^{iny}: m, n \in \mathbb{Z}\}$ 构成 $L^2([0,2\pi]\times[0,2\pi])$ 的标准正交基。

#### Proof:

令 $h_{mn} = e^{imx}e^{iny}$，

$$\langle h_{mn}, h_{mn} \rangle = \iint_\Omega h_{mn}\,\overline{h_{mn}}\,\frac{dx\,dy}{4\pi^2} = \frac{1}{4\pi^2}\int_0^{2\pi}dx\int_0^{2\pi}dy = 1.$$

令 $m_1 \ne m_2$，$n_1 \ne n_2$，

$$\langle h_{m_1 n_1}, h_{m_2 n_2} \rangle = \frac{1}{4\pi^2}\int_0^{2\pi}e^{i(m_1-m_2)x}\,dx \int_0^{2\pi}e^{i(n_1-n_2)y}\,dy = 0.$$

故 $\{h_{mn}: m, n \in \mathbb{Z}\}$ 为一组标准正交系，那么可以把 $\{h_{mn}: m, n \in \mathbb{Z}\}$ 扩张成标准正交基。

而 $\{h_{mn}: m, n \in \mathbb{Z}\}$ 为可数的，与正交基等势。

故 $\{e^{imx}e^{iny}: m, n \in \mathbb{Z}\}$ 为一组标准正交基。 $\blacksquare$

**(ii)** $\{h_m: m=1,2,\ldots,n\}$ 为一组标准正交基。

7. 令 $\omega(t)$ 为 $\mathbb{R}$ 上 Lebesgue 可积的非负函数，令

$$H = \left\{f \mid f\ \text{为}\ \mathbb{R}\ \text{上 Lebesgue 可测函数},\ \int_\mathbb{R}|f|^2\omega\,dt < \infty\right\},$$

证明 $H$ 按内积 $\displaystyle\langle f, g \rangle = \int_\mathbb{R} f\bar{g}\,\omega\,dt$，$\forall f, g \in H$，成为 Hilbert 空间。

#### Proof:

共轭对称性：

$$\langle g, f \rangle = \int_\mathbb{R}\bar{g}f\,\omega\,dt = \int_\mathbb{R}f\bar{g}\,\omega\,dt = \overline{\langle f, g \rangle}. \quad \checkmark$$

令 $h, f, g \in H$，$\alpha, \beta \in \mathbb{K}$：

$$\langle \alpha f + \beta h, g \rangle = \int_\mathbb{R}(\alpha f + \beta h)\bar{g}\,\omega\,dt = \alpha\int_\mathbb{R}f\bar{g}\,\omega\,dt + \beta\int_\mathbb{R}h\bar{g}\,\omega\,dt,$$

即 $\langle \alpha f + \beta h, g \rangle = \alpha\langle f, g \rangle + \beta\langle h, g \rangle$。 $\checkmark$

正定性：$|f|^2\omega \ge 0$，$\langle f, f \rangle = \int_\mathbb{R}|f|^2\omega\,dt \ge 0$，

$$\langle f, f \rangle = 0 \iff |f|^2 = 0\ \text{a.e.} \iff f = 0\ \text{a.e.} \quad \checkmark$$

故 $(H, \langle\cdot,\cdot\rangle)$ 为内积空间。

**完备性：** 令 $\{f_n\}_{n=1}^\infty \subset H$ 为 Cauchy 列，即

$$\|f_n - f_m\|^2 = \int_\mathbb{R}|f_n - f_m|^2\omega\,dt \to 0 \quad (n, m \to \infty).$$

取 $\{f_{n_k}\} \subset \{f_n\}$，使得 $\|f_{n_{k+1}} - f_{n_k}\| < \dfrac{1}{2^k}$，$k = 1, 2, \ldots$。

令 $\displaystyle g_k(t) = \sum_{k=1}^K |f_{n_{k+1}}(t) - f_{n_k}(t)|$，

$$\|g_k\| \le \sum_{k=1}^K\|f_{n_{k+1}} - f_{n_k}\| < \sum_{k=1}^K\frac{1}{2^k} < 1,$$

故 $\int_\mathbb{R} g_k^2\omega\,dt < 1$。

由单调收敛定理，$g_k \to g$，$\int g^2\omega\,dt \le 1 < \infty$。

$g < \infty$ a.e.，$f_{n_1}(t) + \sum_{k=1}^\infty\bigl(f_{n_{k+1}}(t) - f_{n_k}(t)\bigr)$ 绝对收敛 a.e.。

令 $\displaystyle f(t) = \lim_{k\to\infty} f_{n_k}(t)$。

$\forall \varepsilon > 0$，$\exists N$，当 $m, n \ge N$ 时，$\|f_n - f_m\| < \varepsilon$。

令 $k$ 充分大时，$n_k \ge N$，对 $j \ge k$ 有 $\|f_{n_j} - f_{n_k}\| < \varepsilon$。由 Fatou 引理，

$$\int |f - f_{n_k}|^2\omega\,dt \le \liminf_{j\to\infty}\int |f_{n_j} - f_{n_k}|^2\omega\,dt \le \varepsilon^2.$$

故 $f - f_{n_k} \in H \implies f \in H$，即 $f_{n_k} \to f$（依范数）。

$\forall n \ge N$，则 $\|f_n - f\| \le \|f_n - f_{n_k}\| + \|f_{n_k} - f\| < \varepsilon + \varepsilon = 2\varepsilon$。

故 $f_n \to f$（依范数），$H$ 完备。 $\blacksquare$ 

8. 令 $\mathcal{F} = \{e_1, e_2, \ldots\}$ 为 Hilbert 空间 $(H, \langle\cdot,\cdot\rangle)$ 的一组标准正交基系，将 $\mathcal{F}$ 重排成另一个序列 $\{e_1', e_2', \ldots\}$。证明：$\forall x \in H$，

$$\lim_{n\to\infty}\sum_{k=1}^n \langle x, e_k\rangle e_k = \lim_{n\to\infty}\sum_{k=1}^n \langle x, e_k'\rangle e_k'.$$

#### Proof:

显然，这两组标准正交系都为标准正交基。

由 $\displaystyle\left\|x - \sum_{k=1}^n \langle x, e_k\rangle e_k\right\| \to 0\ (n\to\infty)$。

$\forall \varepsilon > 0$：

- $\exists N_1 > 0$，使 $\displaystyle\left\|x - \sum_{k=1}^n \langle x, e_k\rangle e_k\right\| < \varepsilon$，只要 $n > N_1$；
- $\exists N_2 > 0$，使 $\displaystyle\left\|x - \sum_{k=1}^n \langle x, e_k'\rangle e_k'\right\| < \varepsilon$，只要 $n > N_2$。

取 $N = \max\{N_1, N_2\}$。

$$\begin{aligned}
&\left\|\sum_{k=1}^n \langle x, e_k\rangle e_k - \sum_{k=1}^n \langle x, e_k'\rangle e_k'\right\| \\
&\quad \le \left\|\sum_{k=1}^n \langle x, e_k\rangle e_k - f\right\| + \left\|f - \sum_{k=1}^n \langle x, e_k'\rangle e_k'\right\| \\
&\quad < \varepsilon + \varepsilon = 2\varepsilon.
\end{aligned}$$

故 $\displaystyle\lim_{n\to\infty}\sum_{k=1}^n \langle x, e_k\rangle e_k = \lim_{n\to\infty}\sum_{k=1}^n \langle x, e_k'\rangle e_k'$。 $\blacksquare$

10. 令 $\displaystyle f_0 = \sum_{n=1}^\infty \frac{1}{n}(\cos nx + \sin nx) + 1$，令 $H$ 为 $L^2[0, 2\pi]$ 中由 $\{f_0, \cos x, \sin x, \cos 2x, \sin 2x, \ldots\}$ 张成的线性空间，给出 $H$ 中一组完全标准正交系但不完备的。

#### 解:

令 $\displaystyle\langle f, g \rangle = \int_0^{2\pi} f\bar{g}\,dx$。

$\{\cos x, \sin x, \ldots, \cos nx, \sin nx, \ldots\}$ 为一组正交函数系。

取

$$\mathcal{E} = \left\{\frac{\cos nx}{\sqrt{\pi}},\ \frac{\sin nx}{\sqrt{\pi}}\right\}_{n=1}^\infty.$$

容易发现：

$$\frac{1}{\pi}\int_0^{2\pi}\cos mx\cos nx\,dx = \begin{cases} 1, & m = n \\ 0, & m \ne n \end{cases}$$

$$\frac{1}{\pi}\int_0^{2\pi}\sin mx\sin nx\,dx = \begin{cases} 1, & m = n \\ 0, & m \ne n \end{cases}$$

$$\frac{1}{\pi}\int_0^{2\pi}\sin mx\cos nx\,dx = 0.$$

故 $\mathcal{E}$ 为标准正交系。

若 $h \in H$ 且 $h \perp \mathcal{E}$，由定义

$$h = a_0 f_0 + \sum_{n=1}^N(a_n\cos nx + b_n\sin nx).$$

$\forall k > N$，有 $\langle h, \cos kx \rangle = a_0\langle f_0, \cos kx\rangle = a_0\dfrac{\pi}{k} = 0 \implies a_0 = 0$。

令 $h \perp \cos kx$，$h \perp \sin kx$（$1 \le k \le N$）$\implies a_k = b_k = 0$。

即 $h = 0$，$\mathcal{E}$ 在 $H$ 中完全。

发现

$$\langle f_0, e_{n,c} \rangle = \frac{1}{\sqrt{\pi}}\cdot\frac{\pi}{n} = \frac{\sqrt{\pi}}{n}, \qquad \langle f_0, e_{n,s} \rangle = \frac{\sqrt{\pi}}{n}.$$

于是

$$\sum_{n=1}^\infty\bigl(|\langle f_0, e_{n,c}\rangle|^2 + |\langle f_0, e_{n,s}\rangle|^2\bigr) = 2\pi\sum_{n=1}^\infty\frac{1}{k^2} = \frac{\pi^3}{3}.$$

而

$$\|f_0\|^2 = \frac{\pi^3}{3} + |\langle f_0, e_0\rangle|^2 = 2\pi + \frac{\pi^3}{3} \ne \frac{\pi^3}{3}.$$

故不完备。

（其中 $\displaystyle e_{n,s} = \frac{1}{\sqrt{\pi}}\sin nx$，$\displaystyle e_{n,c} = \frac{1}{\sqrt{\pi}}\cos nx$。）

$\mathcal{E}$ 为我们所要求的。 $\blacksquare$

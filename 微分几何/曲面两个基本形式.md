# 微分几何习题

## 一、

### 1. 求出下列曲面的参数表达式

**题目：**

(1) $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$

(2) $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 1$

(4) $z = \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2}$

**解：**

(1)

$\boldsymbol{r}(\theta, \varphi) = (a\cos\theta\cos\varphi,\; b\cos\theta\sin\varphi,\; c\sin\theta)$

(2)

$\boldsymbol{r}(\theta, t) = \left(a\sqrt{1+t^2}\cos\theta,\; b\sqrt{1+t^2}\sin\theta,\; ct\right)$

(4)

$\boldsymbol{r}(u, v) = (au,\; bv,\; u^2 + v^2)$

### 7. 求椭球面的第一基本形式

**解：** 对于 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ 的参数表达式

$\boldsymbol{r}(\theta, \varphi) = (a\cos\theta\cos\varphi,\; b\cos\theta\sin\varphi,\; c\sin\theta)$

求偏导：

$\boldsymbol{r}_\theta = (-a\sin\theta\cos\varphi,\; -b\sin\theta\sin\varphi,\; c\cos\theta)$

$\boldsymbol{r}_\varphi = (-a\sin\varphi\cos\theta,\; b\cos\theta\cos\varphi,\; 0)$

计算第一基本形式系数：

$E = \langle \boldsymbol{r}_\theta, \boldsymbol{r}_\theta \rangle = a^2\sin^2\theta\cos^2\varphi + b^2\sin^2\theta\sin^2\varphi + c^2\cos^2\theta$

$F = \langle \boldsymbol{r}_\theta, \boldsymbol{r}_\varphi \rangle = (a^2 - b^2)\sin\theta\cos\theta\sin\varphi\cos\varphi$

$G = \langle \boldsymbol{r}_\varphi, \boldsymbol{r}_\varphi \rangle = a^2\sin^2\varphi\cos^2\theta + b^2\cos^2\theta\cos^2\varphi$

故

$ds^2 = E\,d\theta^2 + 2F\,d\theta d\varphi + G\,d\varphi^2$

展开为：

$\begin{aligned}
ds^2 ={}& \left(a^2\sin^2\theta\cos^2\varphi + b^2\sin^2\theta\sin^2\varphi + c^2\cos^2\theta\right)d\theta^2 \\
&+ 2(a^2 - b^2)\sin\theta\cos\theta\sin\varphi\cos\varphi\,d\theta d\varphi \\
&+ \left(a^2\sin^2\varphi\cos^2\theta + b^2\cos^2\theta\cos^2\varphi\right)d\varphi^2
\end{aligned}$

### 8. 求下列曲面的第一基本形式

**题目：**

(1) $\boldsymbol{r}(u,v) = (u\cos v,\; u\sin v,\; bv)$

(2) $\boldsymbol{r}(u,v) = (a(u+v),\; b(u-v),\; u^2+v^2)$

**解：**

(1)求偏导：

$\boldsymbol{r}_u = (\cos v,\; \sin v,\; 0)$

$\boldsymbol{r}_v = (-u\sin v,\; u\cos v,\; b)$

计算系数：

$E = \langle \boldsymbol{r}_u, \boldsymbol{r}_u \rangle = \cos^2 v + \sin^2 v = 1$

$F = \langle \boldsymbol{r}_u, \boldsymbol{r}_v \rangle = -u\sin v\cos v + u\cos v\sin v = 0$

$G = \langle \boldsymbol{r}_v, \boldsymbol{r}_v \rangle = u^2\sin^2 v + u^2\cos^2 v + b^2 = u^2 + b^2$

故

$ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2$

即

$ds^2 = du^2 + (u^2 + b^2)dv^2$

(2) 求偏导：

$\boldsymbol{r}_u = (a,\; b,\; 2u)$

$\boldsymbol{r}_v = (a,\; -b,\; 2v)$

计算系数：

$E = \langle \boldsymbol{r}_u, \boldsymbol{r}_u \rangle = a^2 + b^2 + 4u^2$

$F = \langle \boldsymbol{r}_u, \boldsymbol{r}_v \rangle = a^2 - b^2 + 4uv$

$G = \langle \boldsymbol{r}_v, \boldsymbol{r}_v \rangle = a^2 + b^2 + 4v^2$

故

$ds^2 = (a^2 + b^2 + 4u^2)du^2 + 2(a^2 - b^2 + 4uv)du\,dv + (a^2 + b^2 + 4v^2)dv^2$

### 9. 求曲面 $z = f(x,y)$ 的第一基本形式

**解：** 曲面对应的参数表达式为

$\boldsymbol{r}(x,y) = (x,\; y,\; f(x,y))$

求偏导：

$\boldsymbol{r}_x = (1,\; 0,\; f_x), \qquad \boldsymbol{r}_y = (0,\; 1,\; f_y)$

计算系数：

$E = \langle \boldsymbol{r}_x, \boldsymbol{r}_x \rangle = 1^2 + f_x^2$

$F = \langle \boldsymbol{r}_x, \boldsymbol{r}_y \rangle = f_x f_y$

$G = \langle \boldsymbol{r}_y, \boldsymbol{r}_y \rangle = 1 + f_y^2$

故

$ds^2 = E\,dx^2 + 2F\,dx\,dy + G\,dy^2$

即

$ds^2 = (1 + f_x^2)dx^2 + 2f_x f_y\,dx\,dy + (1 + f_y^2)dy^2$

### 11. 参数变换下法向量指向的讨论

**题目：** 令 $(x,y)$ 为曲面 $\boldsymbol{r}(u,v)$ 的另一组参数，请问 $\boldsymbol{r}_u \wedge \boldsymbol{r}_v$ 与 $\boldsymbol{r}_x \wedge \boldsymbol{r}_y$ 的指向是否相同？

**解：** 不一定相同。记 $(x,y)$ 与 $(u,v)$ 之间的变换为 $u = u(x,y),\; v = v(x,y)$。

由链式法则：

$\boldsymbol{r}_x = \boldsymbol{r}_u u_x + \boldsymbol{r}_v v_x, \qquad \boldsymbol{r}_y = \boldsymbol{r}_u u_y + \boldsymbol{r}_v v_y$

那么

$\boldsymbol{r}_x \wedge \boldsymbol{r}_y = (u_x v_y - v_x u_y)\,\boldsymbol{r}_u \wedge \boldsymbol{r}_v$

记雅可比行列式

$J = \frac{\partial(u,v)}{\partial(x,y)} = u_x v_y - v_x u_y$

* $J > 0$ 时，它们指向相同；

* $J < 0$ 时，它们的指向相反。

### 14. 求习题 8 中曲面的第二基本形式

(1) 

已知：

$\boldsymbol{r}_u = (\cos v,\; \sin v,\; 0), \qquad \boldsymbol{r}_v = (-u\sin v,\; u\cos v,\; b)$

求叉积：

$\boldsymbol{r}_u \wedge \boldsymbol{r}_v = (b\sin v,\; -b\cos v,\; u)$

单位法向量：

$\boldsymbol{n} = \frac{\boldsymbol{r}_u \wedge \boldsymbol{r}_v}{|\boldsymbol{r}_u \wedge \boldsymbol{r}_v|} = \left(\frac{b}{\sqrt{b^2+u^2}}\sin v,\; -\frac{b}{\sqrt{u^2+b^2}}\cos v,\; \frac{u}{\sqrt{u^2+b^2}}\right)$

求二阶偏导：

$\boldsymbol{r}_{uu} = (0,0,0)$

$\boldsymbol{r}_{uv} = (-\sin v,\; \cos v,\; 0)$

$\boldsymbol{r}_{vv} = (-u\cos v,\; -u\sin v,\; 0)$

第二基本形式系数：

$L = \langle \boldsymbol{r}_{uu}, \boldsymbol{n} \rangle = 0$

$M = \langle \boldsymbol{r}_{uv}, \boldsymbol{n} \rangle = \frac{b}{\sqrt{u^2+b^2}}$

$N = \langle \boldsymbol{r}_{vv}, \boldsymbol{n} \rangle = 0$

故

$\mathrm{II} = L\,du^2 + 2M\,du\,dv + N\,dv^2$

即

$\mathrm{II} = \frac{2b}{\sqrt{u^2+b^2}}\,du\,dv$

(2) 

已知：

$\boldsymbol{r}_u = (a,\; b,\; 2u), \qquad \boldsymbol{r}_v = (a,\; -b,\; 2v)$

求二阶偏导：

$\boldsymbol{r}_{uu} = (0,0,2), \qquad \boldsymbol{r}_{uv} = (0,0,0), \qquad \boldsymbol{r}_{vv} = (0,0,2)$

求叉积：

$\boldsymbol{r}_u \wedge \boldsymbol{r}_v = (2bu + 2bv,\; 2au - 2av,\; -2ab)$

单位法向量：

$\boldsymbol{n} = \frac{\boldsymbol{r}_u \wedge \boldsymbol{r}_v}{|\boldsymbol{r}_u \wedge \boldsymbol{r}_v|} =
\left(
\frac{bu+bv}{\sqrt{(bu+bv)^2 + (au-av)^2 + a^2b^2}},\;
\frac{au-av}{\sqrt{(bu+bv)^2 + (au-av)^2 + a^2b^2}},\;
\frac{-ab}{\sqrt{(bu+bv)^2 + (au-av)^2 + a^2b^2}}
\right)$

第二基本形式系数：

$L = \langle \boldsymbol{r}_{uu}, \boldsymbol{n} \rangle = -\frac{2ab}{\sqrt{(bu+bv)^2 + (au-av)^2 + a^2b^2}}$

$M = \langle \boldsymbol{r}_{uv}, \boldsymbol{n} \rangle = 0$

$N = \langle \boldsymbol{r}_{vv}, \boldsymbol{n} \rangle = L$

故

$\mathrm{II} = L\,du^2 + 2M\,du\,dv + N\,dv^2 = -\frac{2ab(du^2 + dv^2)}{\sqrt{(bu+bv)^2 + (au-av)^2 + a^2b^2}}$

### 15. 求曲面 $z = f(x,y)$ 的第二基本形式

**解：** 对应的参数表达式为

$\boldsymbol{r}(x,y) = (x,\; y,\; f(x,y))$

求偏导：

$\boldsymbol{r}_x = (1,\; 0,\; f_x), \qquad \boldsymbol{r}_y = (0,\; 1,\; f_y)$

求叉积：

$\boldsymbol{r}_x \wedge \boldsymbol{r}_y = (-f_x,\; -f_y,\; 1)$

单位法向量：

$\boldsymbol{n} = \frac{\boldsymbol{r}_x \wedge \boldsymbol{r}_y}{|\boldsymbol{r}_x \wedge \boldsymbol{r}_y|} =
\left(
\frac{-f_x}{\sqrt{f_x^2 + f_y^2 + 1}},\;
\frac{-f_y}{\sqrt{f_x^2 + f_y^2 + 1}},\;
\frac{1}{\sqrt{f_x^2 + f_y^2 + 1}}
\right)$

求二阶偏导：

$\boldsymbol{r}_{xx} = (0,0,f_{xx}), \qquad \boldsymbol{r}_{xy} = (0,0,f_{xy}), \qquad \boldsymbol{r}_{yy} = (0,0,f_{yy})$

第二基本形式系数：

$L = \langle \boldsymbol{r}_{xx}, \boldsymbol{n} \rangle = \frac{f_{xx}}{\sqrt{f_x^2 + f_y^2 + 1}}$

$M = \langle \boldsymbol{r}_{xy}, \boldsymbol{n} \rangle = \frac{f_{xy}}{\sqrt{f_x^2 + f_y^2 + 1}}$

$N = \langle \boldsymbol{r}_{yy}, \boldsymbol{n} \rangle = \frac{f_{yy}}{\sqrt{f_x^2 + f_y^2 + 1}}$

故

$\mathrm{II} = L\,dx^2 + 2M\,dx\,dy + N\,dy^2$

即

$\mathrm{II} = \left(f_{xx}\,dx^2 + 2f_{xy}\,dx\,dy + f_{yy}\,dy^2\right)\left(f_x^2 + f_y^2 + 1\right)^{-\frac{1}{2}}$

## 二、单位球面的三种参数表示

**题目：** 对于曲面 $S^2(1) = \{(x,y,z) \mid x^2 + y^2 + z^2 = 1\}$，利用三种参数表示，分别确定其切空间和法线，计算第一基本形式与第二基本形式。

### (1) 球坐标参数

参数表示：

$\boldsymbol{r}(\theta, \varphi) = (\cos\theta\cos\varphi,\; \cos\theta\sin\varphi,\; \sin\theta)$

求偏导：

$\boldsymbol{r}_\theta = (-\sin\theta\cos\varphi,\; -\sin\theta\sin\varphi,\; \cos\theta)$

$\boldsymbol{r}_\varphi = (-\cos\theta\sin\varphi,\; \cos\theta\cos\varphi,\; 0)$

**切空间：** $\mathrm{span}\{\boldsymbol{r}_\theta, \boldsymbol{r}_\varphi\}$

求叉积：

$\boldsymbol{r}_\theta \wedge \boldsymbol{r}_\varphi = (-\cos^2\theta\cos\varphi,\; -\cos^2\theta\sin\varphi,\; -\sin\theta\cos\theta)$

**单位法向量：**

$\boldsymbol{n} = \frac{\boldsymbol{r}_\theta \wedge \boldsymbol{r}_\varphi}{|\boldsymbol{r}_\theta \wedge \boldsymbol{r}_\varphi|} = (-\cos\theta\cos\varphi,\; -\cos\theta\sin\varphi,\; -\sin\theta) = -\boldsymbol{r}$

**第一基本形式：**

$E = \langle \boldsymbol{r}_\theta, \boldsymbol{r}_\theta \rangle = 1$

$F = \langle \boldsymbol{r}_\theta, \boldsymbol{r}_\varphi \rangle = 0$

$G = \langle \boldsymbol{r}_\varphi, \boldsymbol{r}_\varphi \rangle = \cos^2\theta$

故

$\mathrm{I} = d\theta^2 + \cos^2\theta\,d\varphi^2$

**第二基本形式：**

$L = -\langle \boldsymbol{r}_\theta, \boldsymbol{n}_\theta \rangle = \langle \boldsymbol{r}_\theta, \boldsymbol{r}_\theta \rangle = 1$

$M = \langle \boldsymbol{r}_\theta, -\boldsymbol{n}_\varphi \rangle = 0$

$N = \langle \boldsymbol{r}_\varphi, -\boldsymbol{n}_\varphi \rangle = \cos^2\theta$

故

$\mathrm{II} = d\theta^2 + \cos^2\theta\,d\varphi^2$



### (2) 直角坐标系参数（上半球面）

参数表示：

$\boldsymbol{r}(x, y) = \left(x,\; y,\; \sqrt{1 - x^2 - y^2}\right)$

求偏导：

$\boldsymbol{r}_x = \left(1,\; 0,\; -\frac{x}{\sqrt{1-x^2-y^2}}\right)$

$\boldsymbol{r}_y = \left(0,\; 1,\; -\frac{y}{\sqrt{1-x^2-y^2}}\right)$

求叉积：

$\boldsymbol{r}_x \wedge \boldsymbol{r}_y = \left(\frac{x}{\sqrt{1-x^2-y^2}},\; \frac{y}{\sqrt{1-x^2-y^2}},\; 1\right)$

**单位法向量：**

$\boldsymbol{n} = \frac{\boldsymbol{r}_x \wedge \boldsymbol{r}_y}{|\boldsymbol{r}_x \wedge \boldsymbol{r}_y|} = \left(x,\; y,\; \sqrt{1 - x^2 - y^2}\right)$

**切空间：** $\mathrm{span}\{\boldsymbol{r}_x, \boldsymbol{r}_y\}$

**第一基本形式系数：**

$E = \langle \boldsymbol{r}_x, \boldsymbol{r}_x \rangle = \frac{1+y^2}{1-x^2-y^2}$

$F = \langle \boldsymbol{r}_x, \boldsymbol{r}_y \rangle = \frac{1-x^2-y^2+xy}{1-x^2-y^2}$

$G = \langle \boldsymbol{r}_y, \boldsymbol{r}_y \rangle = \frac{1+x^2}{1-x^2-y^2}$

故

$\mathrm{I} = (1-x^2-y^2)^{-1}\left[(1+y^2)dx^2 + (1+xy-x^2-y^2)dx\,dy + (1+x^2)dy^2\right]$

**第二基本形式系数：**

$L = -\langle \boldsymbol{r}_x, \boldsymbol{n}_x \rangle = -\frac{1+y^2}{1-x^2-y^2}$

$M = -\langle \boldsymbol{r}_x, \boldsymbol{n}_y \rangle = \frac{x^2+y^2-1-xy}{1-x^2-y^2}$

$N = -\langle \boldsymbol{r}_y, \boldsymbol{n}_y \rangle = \frac{-1-x^2}{1-x^2-y^2}$

故

$\mathrm{II} = -(1-x^2-y^2)^{-1}\left[(1+y^2)dx^2 + (1+xy-x^2-y^2)dx\,dy + (1+x^2)dy^2\right]$

> 下半球面情况类似。

### (3) 球极投影

参数表示：

$\boldsymbol{r}(u, v) = \left(\frac{2u}{1+u^2+v^2},\; \frac{2v}{1+u^2+v^2},\; \frac{u^2+v^2-1}{u^2+v^2+1}\right)$

求偏导：

$\boldsymbol{r}_u = \left(\frac{2+2v^2-2u^2}{(1+u^2+v^2)^2},\; \frac{-4uv}{(1+u^2+v^2)^2},\; \frac{4u}{(1+u^2+v^2)^2}\right)$

$\boldsymbol{r}_v = \left(\frac{-4uv}{(1+u^2+v^2)^2},\; \frac{2+2u^2-2v^2}{(1+u^2+v^2)^2},\; \frac{4v}{(1+u^2+v^2)^2}\right)$

**切空间：** $\mathrm{span}\{\boldsymbol{r}_u, \boldsymbol{r}_v\}$

**单位法向量：**

$\boldsymbol{n} = \frac{\boldsymbol{r}_u \wedge \boldsymbol{r}_v}{|\boldsymbol{r}_u \wedge \boldsymbol{r}_v|} = \left(-\frac{2u}{1+u^2+v^2},\; -\frac{2v}{1+u^2+v^2},\; -\frac{u^2+v^2-1}{u^2+v^2+1}\right) = -\boldsymbol{r}$

**第一基本形式系数：**

$E = \langle \boldsymbol{r}_u, \boldsymbol{r}_u \rangle = \frac{4}{(1+u^2+v^2)^2}$

$F = \langle \boldsymbol{r}_u, \boldsymbol{r}_v \rangle = 0$

$G = \langle \boldsymbol{r}_v, \boldsymbol{r}_v \rangle = \frac{4}{(1+u^2+v^2)^2}$

故

$\mathrm{I} = \frac{4}{(1+u^2+v^2)^2}\left(du^2 + dv^2\right)$

**第二基本形式：**

$\mathrm{II} = \frac{4}{(1+u^2+v^2)^2}\left(du^2 + dv^2\right)$
